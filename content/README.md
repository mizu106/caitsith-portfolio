# caitsith Portfolio

このリポジトリは、学習ログをそのままポートフォリオとして公開するためのものです。

---

## このポートフォリオの思想

- 成果物を作らない
- 無理にまとめない
- 学習ログをそのまま公開する

---

## 運用フロー

1. Obsidianで 「10\_日付順メモ」 に学習メモを書く
2. GitHubにpush
3. GitHub Pagesで自動公開

---

## 重要なルール

- 見せるために書かない
- 学習を最優先
- 継続できる形を壊さない
