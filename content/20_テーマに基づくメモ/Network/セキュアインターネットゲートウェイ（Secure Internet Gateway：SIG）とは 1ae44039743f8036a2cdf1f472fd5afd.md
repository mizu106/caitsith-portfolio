# セキュアインターネットゲートウェイ（Secure Internet Gateway：SIG）とは

セキュアインターネットゲートウェイ（Secure Internet Gateway：SIG）とは、==クラウドベースのセキュリティソリューションで、企業のネットワークをインターネットに安全に接続するサービス==です。

SIGの主な機能は次のとおりです。ウェブフィルタリング、マルウェア対策、脅威インテリジェンス、 セキュリティポリシーの適用。

SIGの導入のメリットとしては、次のようなものがあります。

- オフィス内外問わず従業員の安全なインターネットアクセスを確保できる
- インターネット上での不正なアクティビティや攻撃から組織を保護できる
- 従来のファイアウォールやプロキシサーバーと異なり、柔軟性と効率性を提供できる

SIGの導入が検討されている背景としては、次のようなものがあります。

- 多くの企業がクラウドサービスを活用している
- 働く場所が会社以外に自宅や外出先などでのリモートワークが増えている
- データセンターを境界として内部を守れば安全という考えから、情報資産を置くクラウドやアクセス元が境界の外部となった
