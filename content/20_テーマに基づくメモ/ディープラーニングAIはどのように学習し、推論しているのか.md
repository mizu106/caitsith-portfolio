## [[ディープラーニング]]の基本
### ノードの構造
- 一つのノードで考える場合の構造
  (出力) y = a × x + b
![[Pasted image 20250817210008.png]]

### 発展型、複数入力版
- 以下の式で表現可能
  (出力)　y = a1 × x1 + a2 × x2 + a3 × x3 + b
![[Pasted image 20250817210312.png]]

### 活性化関数  
- [[ディープラーニング]]ではノードとエッジを以下のように表現する。
  w：[[ウエイト]]
  b：[[バイアス]]
  x：入力
  y：出力
- １つのノードの処理を以下の式で表現可能
  y = w1 × x1 + w2 × x2 + w2 × x2 + b
- 活性化関数は最終的な出力を決める仕組み。これまでのノードの作りでは線形の結果しか出ない。
- 活性化関数の例　→　非線形にする関数
  [[ReLU関数]]：y>0 → y、y<=0 → 0
![[Pasted image 20250817032416.png]]

### ノードの多層化
- １ノードの処理で結果を出力するのではなく、隠れ層を追加して処理結果を複雑に計算できるようにする。
- 各層の出力を次の層の入力に使用することで、複雑な学習が可能になる。
- 出力層を複数ノードにして２値以外の結果を表現する為に、[[Softmax関数]]を使用してそれぞれの結果が何%の可能性で正解なのか表現できるようにしている。
![[Pasted image 20250817211850.png]]

### 損失
- 正解と[[ディープラーニング]]の出力の差を損失といい、予想を１回する毎に損失を小さくするよう[[ウエイト]]と[[バイアス]]を調整していく。

1. 出力（推論結果）と正解（ラベル）の差を出す。
2. 差を２乗する（絶対値にして放物線に変換する、このあと傾きを求めるため）
3. 差の２乗した値から、傾きを計算して最小になるよう[[ウエイト]]を調整する。
4. 出力側から入力側に遡って調整していくことを、[[誤差逆伝播法]]という。

![[Pasted image 20250817213001.png]]

### 大量の学習を表現する用語
- １回の学習：１イテレーション
- １イテレーション = サンプル数 = [[バッチサイズ]]
- 大量のサンプル = nイテレーション = １[[エポック]]

## DeepLearningのパラメータについて
- 「◯億個のパラメータ」という場合のパラメータは、ざっくりいうとウエイトとバイアスの数のこと。
- w：ウエイトとは
  各層ニューロン（あるいはトークン埋め込み行列、自己注意機構のQ/K/V行列、フィードフォワード層の線形変換行列など）が入力をどの程度反映するかを定めるスカラー値のこと。
- b：バイアスとは
  wに定数を足し込むパラメータのこと。
- パラメータの例：GPT-3（175Bパラメータ）、LLaMA2（70Bパラメータ）…Bはビリオン=10億、巨大な行列（Embedding、Attention、MLPなど）の要素としてモデル内に格納される。
