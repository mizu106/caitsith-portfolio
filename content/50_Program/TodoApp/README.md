# TodoApp ([[Obsidian]] Vault 内)

- 使い方:
  - `Obsidian_Vault/TodoApp/index.html` をブラウザで開く（ダブルクリックでOK）
  - 追加フォームにタスクを入力して Enter または「追加」ボタン
  - フィルター（全て/アクティブ/完了）、検索、タグ（#タグ形式）、期日、優先度を利用可能
  - データはブラウザの localStorage に自動保存されます

- エクスポート/インポート:
  - フッターの「エクスポート」で JSON をダウンロード
  - 「インポート」で以前に保存した JSON を読み込み

- 備考:
  - 完全クライアントサイドで動作（オフライン可）
  - [[Obsidian]] の外から開いても利用可能
